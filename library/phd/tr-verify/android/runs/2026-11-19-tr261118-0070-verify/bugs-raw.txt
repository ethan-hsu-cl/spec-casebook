PHA262026-0361  —  PHD-A 20.15.0 - AI_Replace: The preview is not change to new image after tapping the [Create More] button
==============================================================================
  Status     TRCreated
  Product    PhotoDirector Mobile for Android  ·  PHD_Android_Generic 20.19
  Version    20.15.0 / build 202608071942   fixed in 20.19.0.v202611181947
  Severity   2   Priority 1   BugBelong RD
  Creator    WILLY_WU   2026-08-11T11:57:29
  TR         TR260807-075
  Reproduce  3/3   previous build: Unknown

--- Description -------------------------------------------------------------
Repro Steps:
1. Install and Launch APP
2. Enter AI Replace
3. Generate an image
4. Select another image in Artwork
5. Tap the [Create More] button
6. Check the preview

Result:
The preview is not change to new image after tapping the [Create More] button

Expect Result:
Should change to new image

Note:
Device = Samsung S23 (15.0)

--- RD resolution -----------------------------------------------------------
  by ARCHER_CHEN  2026-11-11T15:37:37
  Root cause: Place of checking if need to reset source image is in onCreate(), but in case of AIReplaceActivity -> artwork -> gallery -> create more -> AIReplaceActivity, it use a deep link to bypass image and deep link will enter onResume(), but not enter onCreate()
  Solution:   1.Extract checking if need to reset source image to handleLaunchIntent() and call in onCreate() and onNewIntent()
2.Deep link from artwork then will enter onNewIntent() and enter handleLaunchIntent() to reset source image
  Changeset:  https://github.com/CyberLink-Team/photodirector-android-app/commit/bd243597
bd243597
